# Документация Silsol

Этот каталог описывает будущий сервис Silsol: web-приложение для просмотра и изменения документации через чат с LLM.

Главный поток MVP:

```text
Пользователь -> LLM -> Документация
```

Пользователь видит документацию, но не редактирует её напрямую. Все изменения проходят через чат.

## Рабочие соглашения

- Документация является главным рабочим артефактом.
- Чат является пользовательским интерфейсом для изменения документации.
- Пользователь не редактирует Markdown напрямую в MVP.
- Всё, что LLM добавляет самостоятельно, должно быть помечено как предположение или открытый вопрос.
- Невалидный LLM output не применяется к документации.
- В MVP нет отдельного worker: LLM вызовы выполняются через backend API.
- Каждое успешное изменение документации должно быть связано с сообщением пользователя или системным событием.

## Термины

| Термин | Значение |
| --- | --- |
| Project | Рабочее пространство для одной идеи, продукта или документационного набора |
| Documentation | Текущий Markdown-документ проекта, отображаемый пользователю read-only |
| Chat | Единственный пользовательский способ запросить изменение документации |
| LLM Update | Валидированное изменение документации, созданное LLM по сообщению пользователя |
| Documentation Version | Snapshot документации после успешного изменения |
| Change Summary | Краткое описание того, что изменилось в документации |
