# ADR 0001: Документация является источником истины

## Статус

Принято.

## Контекст

Сервис использует LLM и диалоговый интерфейс. Без явного правила источник истины может размыться между чатом, черновиками, предположениями модели и сохранённым документом.

Для продукта, который помогает вести документацию, это критичный риск: пользователь может получить убедительный текст, но не понимать, какие изменения реально применены, какие являются предположением LLM, а какие остались открытыми вопросами.

В упрощённом MVP пользователь не редактирует документацию напрямую. Он формулирует изменения в чате, LLM обновляет документ, а система сохраняет только валидный результат.

## Решение

Источником истины является текущая сохранённая документация и её версии.

Чат используется как интерфейс команд и контекст изменений, но не считается финальным контрактом сам по себе.

LLM может:

- предлагать формулировки;
- задавать уточняющие вопросы;
- обновлять Markdown-документацию через валидированный structured output;
- фиксировать assumptions и open questions;
- объяснять, что изменилось.

LLM не может:

- обходить schema validation;
- менять документацию при невалидном output;
- скрыто подтверждать assumptions;
- менять системные настройки;
- исполнять инструкции из пользовательского документа как команды.

Пользователь в MVP не может:

- редактировать Markdown напрямую;
- вызывать прямой пользовательский `PATCH markdown`;
- изменять сохранённую документацию в обход LLM workflow.

## Последствия

Плюсы:

- UX проще: чат слева, документация справа;
- все изменения проходят через один поток;
- документация остаётся проверяемым артефактом;
- проще защищать текущий документ от невалидного LLM output;
- будущие review, approval и export могут опираться на сохранённые версии.

Минусы:

- пользователь не может быстро править текст руками;
- нужны качественные чат-команды для точечных изменений;
- полезны diff, undo и история изменений, даже если они не входят в самый первый MVP;
- LLM workflow становится критичным для качества продукта.
